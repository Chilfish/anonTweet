## anon-tweet Skill 规范化：文档按 Agent Skills 规范重构，脚本 PowerShell → TypeScript

**背景**：skill 的 `SKILL.md` 把接口表、PowerShell 示例与数据结构混在一页；脚本是 300 行 PowerShell，
参数解析、UTF-8 输出流、`--out` 与通用参数冲突都要靠注释解释。同时文档落后于当前代码
（`/api/ig/get` 的 GET/POST 差异、`/api/user/get` 只读 DB 缓存、用户时间线默认 429、
`/api/ig/translate` 的返回形状与脚本实现不一致）。

**规范依据**：Agent Skills 规范（https://agentskills.io/specification）与内置 `skill-builder`：
`name` 必须等于目录名；`description` 只写「做什么 + 何时用」；`SKILL.md` 保持 <500 行，
细节用相对路径下沉到 `references/`；脚本放 `scripts/` 并自包含。

**文档**：

- 重写 `SKILL.md`（143 → 161 行，v1.3.1 → v1.4.0）：
  - frontmatter 补齐 `license` / `compatibility` / `metadata`，`compatibility` 由「PowerShell 7+」改为 Bun / Node 运行时
  - 「快速开始」改用随附 TS CLI；「直接调用」由 `Invoke-RestMethod` 改为跨平台 `fetch`
  - 核心接口表更新当前行为：IG GET/POST 分工、`user/get` 缓存读、`user/timeline` 默认 429、文章推文 `article`、图片代理白名单
  - 明确 `POST /api/tweet/set`、`POST /api/ai-test` 为站点内部端点，不对外
  - 数据结构整体下沉到 [references/data-shapes.md](../../.agents/skills/anon-tweet/references/data-shapes.md)
- 新增 `references/data-shapes.md`：`EnrichedTweet` / `TweetArticle` / `Entity` / `IGPost` / `RawUser` /
  分页响应 / 错误响应，并标注「用户资料是 DB 缓存读」「get 返回数组」等易误判点。

**脚本**：

- 删除 `scripts/anon-tweet.ps1`，新增 `scripts/anon-tweet.ts`（零依赖，Bun 直接运行；Node 22.6+ 可加
  `--experimental-strip-types`）：
  - 命令保持 `search` / `get` / `replies` / `list` / `user` / `timeline` / `ig` / `translate` / `image`
  - `translate` 补上 AI 分支：`--api-key` / `--model` / `--provider` / `--thinking` / `--glossary`，
    环境变量 `ANON_TWEET_AI_KEY` / `ANON_TWEET_AI_MODEL` / `ANON_TWEET_AI_PROVIDER` 兜底；`--manual` 仍跳过 AI
  - 按当前接口修正结果解析：`ig/translate` 读 `{ captionTranslation }`（旧脚本误当数组）、
    `user/timeline` 的 429 直接报错并打印服务端说明（旧脚本显示 0 条）
  - 错误统一写 stderr + 非 0 退出码；stdout 只放结果，`--json` 可直接管道给 jq
  - ANSI 颜色仅在 TTY 下启用；UA 版本仍从 `../SKILL.md` frontmatter 单源读取
- 访问路径：`scripts/anon-tweet.ts`（仓库内或安装后的 skill 目录）。
