## Phase 1 实施完成（`@chilfish/tweet@0.2.1`）

### 代码

- 安装 `@chilfish/tweet@0.2.1`（exact），移除直接依赖 `x-client-transaction-id`；`linkedom` 仅测试使用。
- 新增 `app/lib/twitter.server.ts`：`createClient({ keys: env.TWEET_KEYS, logger })`，保留 `fetch*` / `getEnrichedTweet` / `resolveSpaceById` 签名；`getTweets` 父链与 quoted 抓取仍留 app。
- 新增 `app/lib/tweet-normalize.ts`：读 localCache / DB 时把旧字段（`id_str` / `quoted_tweet_id` / `retweetedOrignalId` / `isInlineMeida` / `user.id_str` / `host.id_str`）归一化，避免旧缓存失效。
- 新增 `app/lib/tweet-request-patch.ts`：为 `TweetRequests.details` 补 `fieldToggles`（Article 富文本/全文），对应 [tweet-sdk#4](https://github.com/Chilfish/tweet-sdk/issues/4)。
- 类型：`app/types` 改为包 re-export；`EnrichedTweet` 仅扩展 `autoTranslationEntities` / `visionInfo`；`RawUser = UserData`（修正原先 raw/model 语义错位）。
- 解析：删除 `app/lib/react-tweet/utils` 的 7 个已进包文件，保留 barrel 与 `date-utils.ts`（`Asia/Shanghai` + 中文默认格式）；`app/lib/article/parse.ts`、`app/lib/media-url.ts` 改 re-export。
- 字段 sweep：`id_str→id`、`quoted_tweet_id→quotedTweetId`、`retweetedOrignalId→retweetedOriginalId`、`isInlineMeida→isInlineMedia`；raw fixture / `card` / `entities` / `legacy` 保留 raw 字段。
- 本地化：`localizeCtaLabel`（Learn more → 了解更多）与 `formatSpaceDate`（Sep 17 → 9月17日）保住中文 UI。
- 测试：迁移 20 个 vendor import + 30 个 utils import；`transformUserResponse` / `decodeJetfuelPayload` 未从包导出，测试改为经 `enrichTweet` / `parseTrendingCard` 覆盖；AC-OBS / AC-CARD / AC-TWEET-011 改为装配层/行为断言。
- 删除 `app/lib/rettiwt-api`（148 文件）与 `app/lib/SmartPool.ts`，移除 eslint ignore。
