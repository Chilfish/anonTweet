## llms.txt + openapi.json 接入（✅ 已完成，2026-08-31）

按 [llmstxt.org](https://llmstxt.org/) 规范为 AI 爬虫/代理提供结构化站点与 API 描述：

- **`GET /llms.txt`**（`app/routes/llms.txt.ts`，`text/markdown`）：H1 标题 →
  blockquote 简介 → `## ` 分区（Key Pages / Backend API）→ `- [文本](链接): 描述`
  子弹列表；纯 markdown 无 HTML/表格/代码块；链接全部相对路径（任意域名可用）。
- **`GET /openapi.json`**（`app/routes/openapi.json.ts`，`application/json`）：
  OpenAPI 3.1 全量规范，覆盖 `app/routes.ts` 中 `api/*` 全部 16 条路径
  （tweet get/list/replies/search/set、ig get/translate、user get/timeline、
  ai-test/ai-translation/ai-vision、proxy/image、bili-post），带路径参数、
  query 参数、请求体与响应描述。
- **共享构建器** `app/lib/llms.ts`：`buildLlmsTxt(baseUrl)` +
  `buildOpenApiDoc(baseUrl)`，路由只做序列化（服务端模块，不进客户端 bundle）。
  OpenAPI 响应 schema `$ref` 到 `components.schemas` 内带真实字段的 `EnrichedTweet` /
  `TweetUser` / `Entity` / `IGPost` / `AIVisionInfo` / `RawUser` 等定义；llms.txt 另含
  **Data Shapes** 小节，直接给出搜索/获取推文等常用接口的出入参形态（EnrichedTweet
  字段、nextCursor 分页、search 的 q/type/cursor/count 入参）。
- **测试**：`test/unit/llms.spec.ts` AC-LLMS-001（llms.txt 规范形状 + 全端点覆盖 +
  链接相对化）+ AC-LLMS-002（OpenAPI 3.1 结构 + 路径与端点清单奇偶校验 +
  关键端点参数/请求体齐全）。
- 端点清单变更时同步改 `app/lib/llms.ts`，奇偶校验测试会兜底。
- **门禁**：`bun run typecheck` ✅ / `bun run lint` 0 error ✅ / `bun run test` ✅。
