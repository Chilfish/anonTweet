### F1：dev server 启动崩溃（阶段 0 阻塞项）

**根因（非同环境偶发）**：宿主 shell 把 `NODE_ENV=production` 导出给进程，`react-router dev`

于是整条三层门禁变红。用 `NODE_ENV=development bun run dev` 复现为 200 即锁定根因。

**修复**：`package.json` 的 `dev`/`build` 经 `cross-env` 显式固定 `NODE_ENV=development`
/ `production`（不再依赖外层环境）。**守卫**两条：行为级 AC-DEV-001（集成层断言根页健康，
TestServer 就绪本身就是更强守卫）+ 结构级 AC-DEV-002（脚本必须含模式固定，改回裸命令即红）。

## Instagram Story 列表接入（tray / 精选集）

**触发**：所有者实测反馈输入框不支持 `…/stories/rin_.t710/`（用户当前全部快拍）与
`…/stories/highlights/18104…/`（精选集），要求先跑 SDK 看输出。

### SDK 实测（用 app 自己的 `.env` cookie，dotenv 解析）

- `/stories/{u}/` → 1×`directory`(`type:story`, `count:N`, `expires`) + N×`url`（每 item 一条，
  带 `media_id`/`shortcode`/`date`/`expires`/`story_link_*`）——确认可**扇出**。
- `/stories/highlights/{id}/` → 1×`directory`(`type:highlight`, `highlight_title`) + N×`url`。
- 排障插曲：第一次探针报 “Cookie invalid / User not found” 是**假象**——Bun 自带 `.env` 加载器
  会错误解析该 cookie 值（多出换行），app 走 dotenv 解析正常；非 app 缺陷。

### 根因

1. `extractIGId` 只匹配 `/stories/{user}/{数字}/`：tray 返回 `null`（“无法识别”），精选集被误解析成
   `user="highlights"`。
2. 即便匹配，旧值是 `user/id`（含 `/`），而 `/ins/:id`、`/api/ig/get/:id` 都是单段路由 → **单条
   story 从未真正跑通**；FS 缓存键 `ig-post-user/id` 在 Windows 也是非法文件名。

### 方案与交付

- **canonical id**（单段、`~` 分隔，URL path 与 Windows 文件名均安全）：
  `story~{u}~{m}` / `stories~{u}` / `highlight~{id}` / post·reel 短码不变；新增
  `isIGListId()` / `igIdToSourceUrl()`（`app/lib/url-detect.ts`）。
- **扇出**：`normalizeIGPosts()` 对 story/highlight 逐 `url` 消息产出一张 `IGPost`（id=item 缓存键、
  `expires`/`created_at`/链接贴纸取该 item），音频-only 消息过滤；`normalizeIGPost()` 保留为首项包装。
- **取数**：`getIGPostList()` 新鲜拉取 + 逐 item 落 localCache/DB（合并已有 `captionTranslation`）；
  列表不缓存（故事易变 + 避免列表陈旧），代价为每次一次 `reels_media`。
- **UI（下载优先，按所有者口径二次收敛）**：快拍/精选集用 `IGStoryList`——顶部「共 N 条 · 全选 ·
  下载选中(n) · 全部下载（进度）」+ 每卡勾选框（**默认不选**）+ 媒体/链接贴纸/时间 + 单条下载；
  快拍**只保留下载**，不套用帖子截图/翻译/更多菜单（`IGHeader` 加 `storyMode` 只留返回）。普通
  post/reel 保持 `IGPostList` 单卡 + header 全套操作（行为不变）；`plain-ig` 多卡 SSR。
  下载文件名 `ig-{username}-story-{media shortcode}.{ext}`（`extractIGStoryDownloadItems`）。
- **验收**：`AC-IG-STORY-001~005`（tray 扇出、下载优先列表渲染、逐 item 持久化、URL 往返、
  下载项提取）；`AC-IG-003`（单条 story id 形式）与 `share.spec` 期望同步更新；新增
  `tray-multi.json` fixture。

> 需求口径变更（所有者）：中途明确「ins story 通常就是拿来下载图片/视频，翻译或截图没必要」→
> 列表从「多卡 + 每卡截图/翻译操作」收敛为**下载优先**：默认不勾选，手动选或全部下载。
