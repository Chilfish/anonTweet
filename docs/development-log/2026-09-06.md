# 2026-09-06

## 可安装 PWA + Web Share Target（系统分享直达推文/IG）

**方案**：[docs/features/pwa/web-share-target.md](../features/pwa/web-share-target.md) | **AC**：[verify/acceptance-criteria/AC-pwa.md](../../verify/acceptance-criteria/AC-pwa.md)（AC-PWA-001/002/003）

**背景**：anonTweet 此前无任何 PWA 基建（无 manifest / 无 service worker）。目标是让站点在
Chrome Android 可安装，并作为 Web Share Target 接收系统分享——其它 App 分享 X/IG 链接时选择
Anon Tweet，首页自动预填并提交直达对应内容；不可识别文本则留框报错（与手动粘贴一致）。

**实现要点**：

- 接收点 = **首页 "/"**：`share_target` 用 GET 指向 `/`，不造中转页，复用 `TweetInputForm` 提交逻辑。
- 纯函数拆分：URL 检测 `extractTweetId/extractIGId/detectInputType` 自 `utils.ts` 抽到
  `app/lib/url-detect.ts`（utils 顶层 import UI/toast，纯单测/SSR 不该为它牵连 DOM 链）；
  `utils.ts` re-export 保持既有调用点。新增 `app/lib/share.ts`（pickSharedInput / resolveShareTarget /
  hasSharedContent）。`TweetInputForm` 提交改经 `resolveShareTarget`，加一次性分享落地 effect（ref 守卫）。
- PWA 基建（极简、无新运行时依赖）：`public/manifest.webmanifest`（含 share_target）；由
  `public/icon.webp` 经 magick 生成 512/192 方形 PNG；`public/sw.js` 极简网络透传 SW（同源 GET
  回源、绝不写 Cache、异源/非 GET 交默认，`skipWaiting`+`clients.claim`）；`app/lib/pwa/register.ts`
  仅生产注册；`root.tsx` 加 `<link rel="manifest">` + theme-color + 注册 effect；`vercel.json` 补 manifest
  Content-Type。
- 不用 vite-plugin-pwa/Workbox：SSR 的 HTML 由运行时产出、其 HTML 注入不适用；离线 precache 与
  serverless 导航冲突；以 ~15 行 SW 满足安装判定，零依赖零集成风险。

**门禁**：AC-PWA-001/002（静态，`test/acceptance/ac-pwa.spec.ts`）+ AC-PWA-003（语义，`test/unit/share.spec.ts`）。
真机「安装 + 系统分享」沙箱无设备，已在 AC 文档化交由部署者验证（域名 https://anon-tweet.chilfish.top/）。

**遗留（视觉项，需所有者验收）**：图标为 icon.webp 生成的透明方形 PNG，`theme_color`/maskable
变体观感待微调（仓库惯例）。

## PWA 能力盘点（DevTools 截图对照，capability-audit.md）

**背景**：owner 提供 Application > Service Workers 截图（#6900 activated & running）+ PWA 能力清单，
问「还有哪些未发掘场景」。产出 `docs/features/pwa/capability-audit.md`。

**线上核查（23:1x 直连 https://anon-tweet.chilfish.top/）**：sw.js（993B）与 manifest 均与仓库同源、
`manifest.webmanifest` Content-Type 正确；`<head>` 有 manifest link + theme-color，缺 iOS meta；
manifest 缺 maskable/screenshots/shortcuts。部署同步、SW 健康。

**裁决要点**：不做 = 离线 App 内容/IndexedDB 缓存/Background(Periodic) Sync/Web Push/Badging/Payment/
BT-USB-Serial/Wake Lock/收文件分享（无事件源、匿名无账号、SSR 回源铁律）；延后 = 静态资源缓存（需 ADR
修订 AC-PWA-002）。候选：P0 iOS head meta + maskable（收尾）；P1 share 外发（navigator.share，与现有
share_target 对称）+ manifest shortcuts/screenshots；P2 showSaveFilePicker / 最近查看。待 owner 裁决后
排期（backlog 已更新）。
