## llms.txt 索引化（AGENTS 之外的同类重灾区）

按 llmstxt.org v2 规范复查 agent 入口，发现 `/llms.txt` 犯了同一类错：把 `/openapi.json` 的 schema 抄进索引（`## Data Shapes` 约 1.5KB），并给 agent 一批 POST-only 链接（跟过去只会 405），同时对外宣传了隐藏入口 `/bili`。

### 改动

- `buildLlmsTxt()` 重写为 1.2KB 的纯索引：blockquote 一句话 + 6 条调用约定（HTTP 恒 200 + `success` 判定、timeline 默认关闭、`INS_COOKIES` 缺失返回空数组、`nextCursor` 翻页、图片代理白名单）+ `## Start here` / `## Live examples` / `## Optional`
- Data Shapes 整节移除，字段定义只指向 `/openapi.json`；任务级示例指向 `/skills/anon-tweet/SKILL.md`
- 删除 `apiEndpoints`（16 条）——它与 OpenAPI `paths` 是同一事实的第二份拷贝；AC-LLMS-002 的奇偶校验改为「OpenAPI paths ↔ `EXPECTED_PATHS`」
- POST-only 端点不再作为链接出现；示例链接全部是可 GET 取回的真实 fixture id
- `AC-LLMS-001` 改为「索引而非文档」：体积 < 3000 字符、不内联 schema、不链写端点、不出现 `/bili`；测试同步改写
- `robots.txt`：显式 Allow 只读接口（`/api/tweet/{get,list,replies,search}`、`/api/user/get`、`/api/ig/get`、`/api/proxy/image`），保留 `Disallow: /api/` 兜住写端点
- `sitemap.xml` 移除 `/bili`
- `root.tsx` 增加 `<link rel="describedby" href="/llms.txt" type="text/markdown">`（llms.txt v2 的发现机制）
- `anon-tweet` skill 移除 B 站自用端点行，版本 1.3.0 → 1.3.1

### 未做

- llms.txt v2 建议为内容页提供 `.md` 版本（`page.html.md`）并用 `rel="alternate"` 标注。当前只有 skill 文档是 markdown，推文 / IG / 文章页仍是 HTML；需要单独的渲染器，另开任务。

### 验证

`bunx vitest run test/unit/llms.spec.ts`（20 通过）+ `bun run test`（550 通过）+ `bun run typecheck`。
