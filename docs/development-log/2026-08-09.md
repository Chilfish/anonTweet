### 踩坑

- **Windows `child.kill('SIGTERM')` 不杀进程树**：dev server（vite worker 等）残留持有 stdio pipe，verify 主进程退出后管道不关 → CLI 挂住超时。改用 `spawnSync('taskkill', ['/PID', pid, '/T', '/F'])` 同步杀整个进程树
- **`env.server.ts` dotenv `override: true` + zod `.min(1)`**：隔离外部 key 时把 `GEMINI_API_KEY`/`DEEPSEEK_API_KEY` 置空串会触发 schema 校验失败（`❌ Invalid environment variables` → dev server 崩）。正确隔离 = `DOTENV_CONFIG_PATH` 指向缺失文件阻止 `.env` 加载（override:true 无法用空串覆盖）+ `INS_COOKIES`/`TWEET_KEYS` 空串（schema 允许）+ GEMINI/DEEPSEEK 用 `delete`（留 undefined）
- **AC-SHOT-002 确定性**：本地 `.env` 配了 `INS_COOKIES` 时，dev server 对 bogus id 也会走真实 IG 请求（网络不可达 → 降级渲染 NotFound → 内容断言失败）。`--server` 隔离后 `hasInsCookies=false` → 走 bogus id 确定性路径（渲染 HTML 即 PASS）
