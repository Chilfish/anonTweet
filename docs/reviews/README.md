# 代码审查记录（Reviews）

**项目**: anonTweet

> 代码审查（含 AI 辅助审查）的记录区。每次**里程碑 / 阶段 / 工作流完成**后做一次 review，把问题沉淀到带日期的审查记录，避免同一类问题反复出现。

## 约定

- 文件名：`review-YYYY-MM-DD-<主题>.md`（如 `review-2026-08-13-ai-vision.md`）
- 每条问题带编号前缀（如 `P0/P1/P2` 或 `S1/C1/D1`），标注文件与建议修法
- 审查视角可含：代码正确性、UI/UX、性能、SSR 安全、安全边界（SSRF / 缓存污染）
- 已修问题在原记录中勾选并注明 commit；同类问题升级为 postmortem 或同步到「高频雷区」

## 审查清单（写码/审查时逐项过）

- [ ] 遵循 `../engineering/code-style.md`（catch unknown、无 any、路由薄编排、三态覆盖）
- [ ] SSR 安全：无 render 期浏览器 API、Zustand selector 可缓存
- [ ] 浏览器 bundle 安全：服务端代码未泄漏到客户端
- [ ] 安全边界：SSRF / 未认证写入 / 缓存污染
- [ ] 纯函数 / 新逻辑有测试（test-first，AC 先行）
- [ ] 相关文档已更新（INDEX.md 导航、领域文档、本日开发日志）
- [ ] 新 Bug 模式已写 postmortem
